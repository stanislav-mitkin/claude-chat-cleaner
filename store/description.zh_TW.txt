🗑️ 幾秒內批次刪除 Claude 對話。選取全部或挑選特定聊天 — 一鍵全部刪除。

厭倦了逐條刪除 Claude 聊天記錄？Claude Chat Cleaner 直接在 Claude.ai 側邊欄新增選取模式，讓你一次標記多個對話並批次刪除。非常適合快速整理聊天記錄。

使用方式
————————

1. 開啟 claude.ai
2. 點擊側邊欄中的「Select chats」按鈕 — 或按下 Ctrl+Shift+X（Mac 上為 ⌘⇧X）
3. 點擊任意對話以選取或取消選取
4. 按 Enter 確認（確認 → 再次按 Enter），或點擊刪除按鈕，一次移除所有已選項目

⌨️ 鍵盤快捷鍵
——————————

• Ctrl+Shift+X / ⌘⇧X — 進入 / 退出選取模式
• 點擊 — 選取或取消選取聊天
• Ctrl+A / ⌘A — 選取所有聊天
• Ctrl+D / ⌘D — 清除選取
• Enter → Enter — 刪除已選項目（兩步確認）
• Escape — 退出選取模式

✨ 功能特色
————————

✓ 批次選取並刪除任意數量的對話
✓ 一個快捷鍵即可全選
✓ 兩步刪除確認 — 防止誤刪
✓ 進度條 — 刪除過程中的即時回饋
✓ 樂觀式 UI — 聊天立即消失，出錯時自動還原
✓ 全鍵盤操作工作流程

✓ 無需帳號，無需登入，不收集任何資料

🔒 隱私聲明
————————

Claude Chat Cleaner 不收集、儲存或傳輸任何個人資料。擴充功能僅代表你直接向 Claude 自身的 API 發送刪除請求 — 與你手動刪除聊天時 Claude.ai 執行的請求完全相同。

所需權限：
• claude.ai — 讀取側邊欄並呼叫刪除 API 所必需
