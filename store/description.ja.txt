🗑️ Claudeの会話を数秒で一括削除。すべて選択するか、削除したいチャットを選んで — ワンクリックでまとめて削除できます。

Claudeのチャットをひとつずつ削除するのは面倒ではありませんか？Claude Chat Cleaner は、Claude.aiのサイドバーに選択モードを追加します。複数の会話をまとめてマークして、一度に削除できます。チャット履歴の整理に最適です。

使い方
——————

1. claude.ai を開く
2. サイドバーの「Select chats」ボタンをクリック — または Ctrl+Shift+X（MacはCmd+Shift+X / ⌘⇧X）を押す
3. 会話をクリックして選択または選択解除する
4. Enter キーを押して確認（確認 → もう一度 Enter）するか、「削除」ボタンをクリックする

⌨️ キーボードショートカット
————————————————————————

• Ctrl+Shift+X / ⌘⇧X — 選択モードの開始 / 終了
• クリック — チャットの選択を切り替える
• Ctrl+A / ⌘A — すべてのチャットを選択
• Ctrl+D / ⌘D — 選択をクリア
• Enter → Enter — 選択したチャットを削除（2段階確認）
• Escape — 選択モードを終了

✨ 機能
——————

✓ 何件でも会話をまとめて選択・削除
✓ ショートカット1つですべてを選択
✓ 2段階の削除確認 — 誤削除を防止
✓ プログレスバー — 削除中のリアルタイム進捗表示
✓ 楽観的UI — チャットは即座に消え、エラー時は自動で復元
✓ キーボードだけで完結するワークフロー
✓ 軽量 — バックグラウンドスクリプトなし、外部サーバーへの通信なし
✓ アカウント不要、ログイン不要、データ収集なし

🔒 プライバシー
——————————

Claude Chat Cleaner は個人データを一切収集・保存・送信しません。あなたの代わりに、Claude自身のAPIへ削除リクエストを直接送信するだけです。これは、チャットを手動で削除するときにClaude.aiが行うリクエストとまったく同じです。

要求する権限:
• claude.ai — サイドバーの読み取りと削除APIの呼び出しに必要
