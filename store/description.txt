🗑️ Bulk-delete Claude conversations in seconds. Select all or pick chats — then delete with one click.

Tired of deleting Claude conversations one by one? Claude Chat Cleaner adds a Select mode to the Claude.ai sidebar so you can pick multiple conversations and delete them all at once. Perfect for cleaning up your chat history fast.

HOW IT WORKS
————————————

1. Open claude.ai
2. Click the "Select chats" button in the sidebar — or press Ctrl+Shift+X (⌘⇧X on Mac)
3. Click any conversation to toggle its selection
4. Press Enter (confirm → Enter again) or click Delete to remove them all

⌨️ KEYBOARD SHORTCUTS
——————————————————

• Ctrl+Shift+X / ⌘⇧X — Enter / Exit Select mode
• Click — Toggle chat selection
• Ctrl+A / ⌘A — Select all chats
• Ctrl+D / ⌘D — Clear selection
• Enter → Enter — Delete selected (two-step confirmation)
• Escape — Exit Select mode

🔒 PRIVACY
———————

Claude Chat Cleaner does not collect, store, or transmit any personal data. It only sends delete requests directly to Claude's own API on your behalf — the same requests Claude.ai itself makes when you delete a chat manually.

Permissions requested:
• claude.ai — required to read the sidebar and call the delete API
