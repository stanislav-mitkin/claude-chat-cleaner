🗑️ 几秒内批量删除 Claude 对话。选择全部或挑选特定聊天 — 一键全部删除。

厌倦了逐条删除 Claude 聊天记录？Claude Chat Cleaner 在 Claude.ai 侧边栏中直接添加选择模式，让你一次标记多个对话并批量删除。非常适合快速整理聊天历史。

使用方法
————————

1. 打开 claude.ai
2. 点击侧边栏中的「Select chats」按钮 — 或按下 Ctrl+Shift+X（Mac 上为 ⌘⇧X）
3. 点击任意对话以选中或取消选中
4. 按 Enter 确认（确认 → 再次按 Enter），或点击删除按钮，一次性移除所有已选内容

⌨️ 键盘快捷键
——————————

• Ctrl+Shift+X / ⌘⇧X — 进入 / 退出选择模式
• 点击 — 选中或取消选中聊天
• Ctrl+A / ⌘A — 选择所有聊天
• Ctrl+D / ⌘D — 清除选择
• Enter → Enter — 删除已选项目（两步确认）
• Escape — 退出选择模式

✨ 功能特点
————————

✓ 批量选择并删除任意数量的对话
✓ 一个快捷键即可全选
✓ 两步删除确认 — 防止误删
✓ 进度条 — 删除过程中的实时反馈
✓ 乐观式 UI — 聊天立即消失，出错时自动恢复
✓ 全键盘操作工作流
✓ 轻量级 — 无后台脚本，不连接第三方服务器
✓ 无需账号，无需登录，不收集任何数据

🔒 隐私说明
————————

Claude Chat Cleaner 不收集、存储或传输任何个人数据。扩展程序仅代表你直接向 Claude 自身的 API 发送删除请求 — 与你手动删除聊天时 Claude.ai 执行的请求完全相同。

所需权限：
• claude.ai — 读取侧边栏并调用删除 API 所必需
