🗑️ Claude 대화를 몇 초 만에 일괄 삭제하세요. 전체 선택하거나 원하는 채팅만 골라 — 클릭 한 번으로 삭제할 수 있습니다.

Claude 채팅을 하나씩 지우는 게 지겹지 않으신가요? Claude Chat Cleaner는 Claude.ai 사이드바에 선택 모드를 추가해 여러 대화를 한꺼번에 표시하고 모두 삭제할 수 있게 해줍니다. 채팅 기록을 빠르게 정리하는 데 딱 맞습니다.

사용 방법
—————————

1. claude.ai를 엽니다
2. 사이드바의 «Select chats» 버튼을 클릭하거나 Ctrl+Shift+X (Mac은 ⌘⇧X)를 누릅니다
3. 대화를 클릭해 선택하거나 선택 해제합니다
4. Enter를 누르고(확인 → 다시 Enter) 또는 삭제 버튼을 클릭해 모두 제거합니다

⌨️ 키보드 단축키
——————————————

• Ctrl+Shift+X / ⌘⇧X — 선택 모드 켜기 / 끄기
• 클릭 — 채팅 선택 또는 선택 해제
• Ctrl+A / ⌘A — 모든 채팅 선택
• Ctrl+D / ⌘D — 선택 초기화
• Enter → Enter — 선택 항목 삭제 (2단계 확인)
• Escape — 선택 모드 종료

✨ 기능
——————

✓ 원하는 수만큼 대화를 일괄 선택 및 삭제
✓ 단축키 하나로 전체 선택
✓ 2단계 삭제 확인 — 실수로 지우는 일 없음
✓ 진행 표시줄 — 삭제 중 실시간 피드백
✓ 낙관적 UI — 채팅이 즉시 사라지고 오류 시 자동 복원
✓ 완전한 키보드 기반 워크플로
✓ 가볍습니다 — 백그라운드 스크립트 없음, 외부 서버 통신 없음
✓ 계정 불필요, 로그인 불필요, 데이터 수집 없음

🔒 개인정보 보호
———————————

Claude Chat Cleaner는 개인 데이터를 수집, 저장하거나 전송하지 않습니다. 오직 여러분을 대신해 Claude 자체 API에 직접 삭제 요청을 보낼 뿐입니다 — 채팅을 수동으로 삭제할 때 Claude.ai가 수행하는 것과 동일한 요청입니다.
