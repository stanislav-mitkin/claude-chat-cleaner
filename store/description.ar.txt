🗑️ احذف محادثات Claude بشكل جماعي في ثوانٍ. اختر الكل أو حدد المحادثات التي تريدها — واحذفها بنقرة واحدة.

سئمت من حذف محادثات Claude واحدة تلو الأخرى؟ يضيف Claude Chat Cleaner وضع التحديد مباشرةً إلى شريط جانب Claude.ai حتى تتمكن من تحديد عدة محادثات ومسحها جميعًا دفعةً واحدة. مثالي لتنظيف سجل دردشتك بسرعة.

كيف يعمل
—————————

1. افتح claude.ai
2. انقر فوق زر «Select chats» في الشريط الجانبي — أو اضغط Ctrl+Shift+X (⌘⇧X على Mac)
3. انقر فوق أي محادثة لتحديدها أو إلغاء تحديدها
4. اضغط Enter (تأكيد → اضغط Enter مرة أخرى) أو انقر فوق حذف لإزالة جميع المحدد

⌨️ اختصارات لوحة المفاتيح
————————————————————

• Ctrl+Shift+X / ⌘⇧X — الدخول إلى وضع التحديد / الخروج منه
• النقر — تحديد دردشة أو إلغاء تحديدها
• Ctrl+A / ⌘A — تحديد جميع الدردشات
• Ctrl+D / ⌘D — مسح التحديد
• Enter → Enter — حذف المحدد (تأكيد بخطوتين)
• Escape — الخروج من وضع التحديد

✨ المميزات
——————————

✓ تحديد وحذف أي عدد من المحادثات دفعةً واحدة
✓ تحديد الكل بضغطة مفتاح واحد
✓ تأكيد الحذف بخطوتين — لا حذف عرضي
✓ شريط التقدم — تغذية راجعة فورية أثناء الحذف
✓ واجهة متفائلة — تختفي الدردشات على الفور وتُستعاد تلقائيًا عند حدوث خطأ
✓ سير عمل كامل عبر لوحة المفاتيح
✓ خفيف — بدون نصوص برمجية في الخلفية، بدون اتصال بخوادم جهات خارجية
✓ بدون حساب، بدون تسجيل دخول، بدون جمع بيانات

🔒 الخصوصية
———————

لا يجمع Claude Chat Cleaner أي بيانات شخصية ولا يخزنها ولا يرسلها. يرسل الإضافة فقط طلبات الحذف مباشرةً إلى واجهة برمجة تطبيقات Claude نيابةً عنك — وهي نفس الطلبات التي تُجريها Claude.ai عندما تحذف دردشة يدويًا.
