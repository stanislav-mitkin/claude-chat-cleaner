## Full description

**Tired of deleting Claude conversations one at a time?**

Claude Chat Cleaner adds a fast, keyboard-friendly selection mode directly into the Claude.ai sidebar. Pick any number of chats, then delete them all with a single confirmation — no page reloads, no extra clicks.

---

### How it works

1. Open [claude.ai](https://claude.ai) in Chrome.
2. A small **"Select chats"** button appears in the bottom-right corner.
3. Click it (or press **Ctrl+Shift+X** / **⌘⇧X** on Mac) to enter Selection mode.
4. Click any conversation in the sidebar to toggle it. Or use **Ctrl+A** / **⌘A** to select all at once.
5. Press **Enter** (confirm with a second press), or click the **Delete** button — done.

---

### Features

- **Bulk delete** — remove dozens or hundreds of chats in one action
- **Select all** — Ctrl+A / ⌘A highlights every visible conversation instantly
- **Keyboard-first** — full workflow without touching the mouse: select, confirm, delete
- **Click to toggle** — click individual chats to add or remove them from the selection
- **Progress bar** — real-time feedback while deletions are processed
- **Double-confirm** — a second keypress (or button click) is required before anything is deleted, so accidental wipes are impossible
- **Optimistic UI** — selected chats disappear immediately; restored automatically on API failure
- **Zero tracking** — no analytics, no telemetry, no remote servers; all logic runs locally in the page

---

### Keyboard shortcuts

| Key | Action |
|---|---|
| Ctrl+Shift+X / ⌘⇧X | Toggle Selection mode on/off |
| Click / Space | Toggle hovered chat |
| Ctrl+A / ⌘A | Select all chats |
| Ctrl+D / ⌘D | Clear selection |
| Enter × 2 | Confirm and delete |
| Esc | Exit Selection mode |

---

### Privacy

The extension runs entirely within your browser tab. It calls Claude's own API endpoints — the same ones the website uses — using your existing login session. No data ever leaves your browser to any third-party server.

**Permissions requested:**
- `claude.ai` — required to read the sidebar and call the delete API
